# [FR(AI)L](https://sciproj.ptcris.pt/176786PRJ): Intelligent decision support system for FRAILty assessment in the elderly population


[![Download Latest Release](https://img.shields.io/badge/Download-v0.1-blue?style=for-the-badge&logo=github)](https://github.com/tiagonob80/FRAIL-public/releases/tag/v0.1)

This repository contains the code developed in the [FRAIL project](https://doi.org/10.54499/2024.07266.IACDC) and the decision support tool. 

Once oppening, you can perform **outcomes predictions** using the ML models developed for elderly individuals.
